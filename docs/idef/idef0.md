# IDEF0 (A-0 / A0)

## A-0 Контекст

Функция: **Управлять поставками и контрактами с оценкой рисков по срокам**.

- **Input:** данные контрактов, поставок, события инцидентов, учетные данные пользователей.
- **Control:** роли и политики безопасности, регламенты SLA, договорные условия.
- **Output:** риск-оценки, эскалации, штрафы, аналитические отчеты.
- **Mechanism:** JavaFX клиент, TCP сервер Java 21, PostgreSQL, Hibernate/JPA.

## A0 Декомпозиция

- **A1:** Управление пользователями и ролями.
- **A2:** Ведение поставщиков, контрактов и поставок.
- **A3:** Анализ сроков и вычисление рисков.
- **A4:** Управление инцидентами и эскалациями.
- **A5:** Расчет штрафов и формирование отчетности.
