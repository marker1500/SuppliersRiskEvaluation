# IDEF1X (концептуальная модель)

Сущности и ключевые связи:

- `USER` 1..N `USER_ROLE` (идентифицирующая связь)
- `SUPPLIER` 1..N `CONTRACT` (неидентифицирующая)
- `CONTRACT` 1..N `SHIPMENT` (неидентифицирующая)
- `CONTRACT` 1..N `RISK_ASSESSMENT` (неидентифицирующая)
- `SHIPMENT` 1..N `INCIDENT` (неидентифицирующая)

Нормализация до 3НФ:

1. 1НФ: атомарные атрибуты в каждой таблице, отсутствие повторяющихся групп.
2. 2НФ: устранены частичные зависимости неключевых атрибутов от части составного ключа.
3. 3НФ: устранены транзитивные зависимости, атрибуты зависят только от первичного ключа.

Ограничения:

- PK для всех таблиц;
- FK для всех межтабличных связей;
- `UNIQUE` для `users.username`, `suppliers.name`, `contracts.contractNumber`;
- NOT NULL для обязательных атрибутов.
